# Widget Kit  

**Widget Kit** is a simple SwiftUI-based project built to understand how widgets work in iOS using WidgetKit.

---

## Features  

- Small, medium, and large widget support  
- Timeline-based updates  
- Placeholder and snapshot handling  
- Basic SwiftUI widget layouts
